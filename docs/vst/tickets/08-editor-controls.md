# 08: Plugin window with controls

**Goal:** replace the generic editor with TAP's own layout.

## Tasks
- Add a mode picker with each mode's description, shown in the same words as the web app.
- Show only the knobs for the current mode.
- Add knob groups for Synth, Vibrato and Reverb.
- Add a Reset pitches button.

## Prototype
The plugin window in Ableton looks like a smaller version of the web app's options panel.

## Done when
- Every control follows Ableton automation, and the other way round.
