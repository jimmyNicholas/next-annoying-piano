# 02: A plain polyphonic synth

**Goal:** MIDI notes make sound at concert pitch.

## Tasks
- Add a triangle-wave synth voice with Tone.Synth's envelope (attack 0.005, decay 0.1, sustain 0.3, release 1).
- Use a JUCE synthesiser with 32 voices, matching Tone.PolySynth.
- Scale each note's level by its velocity.

## Prototype
Playing an Ableton MIDI clip or a MIDI keyboard gives an ordinary, in-tune synth.

## Done when
- Notes start and stop cleanly with no clicks or stuck notes.
