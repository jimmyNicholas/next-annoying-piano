# 06: Plugin window with controls

**Goal:** replace the generic editor with TAP's own layout.

## Tasks
- Add a mode picker with each mode's description, in the same words as the web app.
- Show only the controls for the current mode.
- Add the Output (MPE or Semitone) switch.
- Add a Reset pitches button.

## Prototype
TAP's window in Ableton looks like a smaller version of the web app's options panel.

## Done when
- Every control follows Ableton automation, and the other way round.
