# 06: Vibrato

**Goal:** match Tone.Vibrato.

## Tasks
- Add a modulated delay line (up to 5 ms) driven by a sine LFO.
- Add parameters: Frequency (1 to 100 Hz, default 5), Depth (0 to 1, default 0.1), Wet (0 to 1, default 1).

## Prototype
Turning Depth up gives an audible wobble. At Wet 0 the sound is the plain synth.

## Done when
- No clicks when parameters change while playing.
