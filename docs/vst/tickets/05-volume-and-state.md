# 05: Volume and saving settings

**Goal:** the plugin behaves like a normal Ableton instrument.

## Tasks
- Add a Volume parameter (-60 to 0 dB) with smoothing.
- Save and restore all parameters with the Ableton set.

## Prototype
Save an Ableton set, close it, reopen it: the mode and settings are restored.

## Done when
- Volume changes without zipper noise.
- Settings survive saving and reopening.
